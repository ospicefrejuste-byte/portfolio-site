Le fichier `public/vendor/kkiapay-2.0.38.js` est une copie inchangée de `dist/k.js` du paquet npm `kkiapay@2.0.38`, auteur déclaré : KkiaPay, licence ISC. Il charge l’interface de paiement officielle à https://widget-v3.kkiapay.me. Son code est chargé sur les pages d’inscription et de gestion ; le widget s’ouvre uniquement au clic sur un paiement configuré. L’API de vérification serveur reprend l’endpoint et les en-têtes du SDK npm `@kkiapay-org/nodejs-sdk@1.0.7` : POST /api/v1/transactions/status, x-api-key, x-private-key, x-secret-key. Aucun secret n’est inclus dans le fichier client.

Les documents PDF sont générés avec `pdfkit@0.17.2` (licence MIT, installé via npm). La police DejaVu Sans est distribuée dans `lib/assets/DejaVuSans.ttf` pour les caractères français ; sa licence figure dans `lib/assets/FONT_LICENSE.txt`. Aucun logo distant n’est téléchargé côté serveur pour la génération des PDF.
