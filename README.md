# Démo des cours de renforcement scolaire

Page publique : inscription puis simulation de paiement Mobile Money. Aucun lien vers la gestion dans le parcours élève.

Page administrateur de démonstration : `/admin-demo.html`. Ce site statique ne fournit pas de connexion sécurisée. Les données sont stockées dans le navigateur et ne sont pas partagées entre appareils. Utiliser uniquement des informations fictives. Les encaissements sont simulés et ne représentent aucun paiement réel.

La version complète avec comptes et permissions côté serveur reste nécessaire pour une utilisation réelle.

## Administration

Le tableau de bord propose les effectifs, les inscriptions validées, les enseignants affectés, les encaissements simulés du mois, les cours et les élèves sans paiement. Les filtres portent sur la classe, le centre et le mois pour les paiements.

Classes & enseignants : affectations dérivées des cours, modifiables dans Cours & planning. Statistiques : distributions, six mois de paiements, présence et moyenne des notes, classement des enseignants par charge (élèves accompagnés puis séances), sans jugement de qualité pédagogique. Un jeu fictif peut être ajouté volontairement sans écraser les dossiers existants.
